# Ai 簡報實驗室｜實證師資班

以「研究設計」為共同主題，練習RCT、世代、病例對照與橫斷面研究的教學。11題，約49分鐘，不含生成等待與講解。

1. 破冰①｜說清楚兩類研究
2. 破冰②｜畫一位 EBM 教師
3. 破冰③｜做研究設計翻卡
4. 提示詞①｜研究設計教學大綱
5. 提示詞②｜產出簡報內文資料
6. 繪圖①｜研究設計簡報封面
7. 繪圖②｜教學檢核結尾資訊圖
8. AI 簡報｜直接製作師資教學 PPT

案例為教學模擬，附CEBM與CASP方法參考。保留單一提示詞、複製按鈕、工具連結與完成紀錄。
開啟index.html即可使用；AI服務需網路及帳號。網站：https://shaoen0926-design.github.io/ebm-faculty-ai-lab/

## 期刊簡報分頁

入口：journal.html。沿用同一篇論文、AI產出的大綱與核對後文案。

- 0 準備：0 使用工具；0.1 使用期刊（課程素材連結）；0.2 課程講義。工具包含ChatGPT、Gemini、Claude、Grok、Copilot、NotebookLM、Canva、Gamma、Google簡報。
- 1 期刊文案萃取：1.1設計簡報大綱；1.2萃取文案與截取期刊圖。
- 2 簡報美編：2.1 NotebookLM美編提示詞；2.2可編輯PPT；2.3繪圖簡報；2.4網頁簡報；2.5動畫HTML簡報。

上課先完成1.1與1.2，再選一種美編路線；完成紀錄獨立保存，0 準備不計入 9 題。
原圖保留出處與完整圖例，生成式圖片不取代原始研究圖表。工具不支援擷取或檔案生成時明確標示，避免虛構檔案。

設計參考（2026-11-07查閱）：
- NotebookLM簡報自訂與來源建議：https://blog.google/innovation-and-ai/models-and-research/google-labs/8-ways-to-make-the-most-out-of-slide-decks-in-notebooklm/
- CASP依研究類型提供評讀工具：https://casp-uk.net/casp-tools-checklists/

- 3 功能頁面製作：3.1整合封面、大綱、章節與Take-home messages，輸入已完成的PPTX，交付完整PPTX；3.2 NBLM 功能頁，依來源製作封面、目錄、章節與結論頁。

期刊簡報 QR code：`journal-qrcode.png`（圖片）、`journal-qrcode.svg`（向量），連至 https://shaoen0926-design.github.io/ebm-faculty-ai-lab/journal.html 。

## 衛教簡報分頁

入口：health.html。參考 https://shaoen0926-design.github.io/osteoporosis-ai-lab/ 的 11 題骨鬆衛教練習，沿用原提示詞與六頁課堂素材。

- 01–03 破冰：衛教短文、水豚醫療人員、衛教重點卡。
- 04–05 內容：衛教簡報大綱、逐頁內文。
- 06–07 圖像：封面、結尾資訊圖。
- 08–11 製作：可編輯 PPT、NotebookLM、圖片簡報、互動衛教網頁。

每題提供提示詞複製與完成紀錄。NotebookLM 提供獨立的共用素材複製按鈕；下載來源為「骨鬆衛教六頁素材.txt」。本頁以繁體中文面向病人及家屬，完成進度與教學、期刊簡報分開保存。
