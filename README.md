2. 破冰②｜畫一位 EBM 教師
3. 破冰③｜做研究設計翻卡
4. 提示詞①｜研究設計教學大綱
5. 提示詞②｜產出簡報內文資料
6. 繪圖①｜研究設計簡報封面
7. 繪圖②｜教學檢核結尾資訊圖
8. AI 簡報｜直接製作師資教學 PPT
9. NotebookLM｜客製簡報風格
10. 圖片簡報｜研究設計比較頁
11. 互動網頁｜研究設計資訊探索
